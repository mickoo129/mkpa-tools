# 【工具全名】

MKPA 工具之一。呢個 repo 只放呢一個工具，獨立部署去 Netlify。

## ⚠️ 開始改之前

- **一定用 GitHub 上最新版本做底**。先 pull／重新讀取 repo 入面嘅檔案，唔好用對話記憶或者之前貼過嘅舊代碼覆蓋，否則會將新設計改返做舊樣。
- 【年 月】建立，一開始已經跟 MKPA 統一設計（宏利綠、Noto Sans HK、電子名片、「列印 / 存 PDF」）。見到呢啲係正常，唔好改返轉頭。

- **刻意同標準唔同嘅改動**（例如呢個工具用另一隻主色、唔要某個標準元素），一定要喺下面「呢個工具嘅特別嘢」寫低改咗咩同原因。冇寫低嘅，之後同步統一標準時會被改返做標準。
- **改工具名、頁頭簡介或者網址**，要同步改 `mickoo129/mkpa-tools` 嘅 `tools.json`（MKPA 工具箱主頁靠佢顯示工具）；冇權限改就提我。
- 一般功能改動（加功能、改計算、改數據、改字眼）唔使寫入 CLAUDE.md；只有刻意唔跟標準、或者將來改嘢要知道嘅重要資料（例如數據來源、特別檔案結構）先要寫。

## 設計標準

完整標準喺 **`mickoo129/mkpa-tools`** 嘅 `CLAUDE.md` 同 `_standard/`（`mkpa.css`、`snippets.html`）。做設計相關改動之前先讀嗰度；如果讀唔到，先問我，唔好自己估。

重點：
- 主色宏利綠 `#00A758`；白底上嘅綠色文字用 `#00753E`；深色（工具名、大標題、頁尾）用深青綠 `#0E5E57`。
- 字體：內文 Noto Sans HK，數字 Barlow；唔用襯線字。
- 聯絡資料**只用電子名片連結**（`https://api.portfoplus.com/api/v1/adviser/5e41564ab3b1bc00153394db?m=link&r=adviser`），唔好加電話、WhatsApp 號碼、電郵或顧問資料輸入欄。
- 頁尾電子名片下面有「MKPA 工具箱」連結（`https://mkpa.netlify.app/`，開新分頁）。
- 一定要有「列印 / 存 PDF」掣；列印版有工具名、列印日期、電子名片二維碼同版權行。
- 唔做深色模式。
- 分類顏色：唔同分類用 `--mk-cat-1`…`8`（1 醫療、2 人壽、3 危疾、4 意外、5 儲蓄／退休、6 癌症、7 中性、8 後備）；冇固定意思嘅分類按 1→8 次序；分類色唔做按鈕、唔代表好壞；按標準「三級用色」：保險分類成頁轉淺底、功能分頁淡底＋色帶、長篇指南章節唔用大面積底色；選中掣用該分類文字色做底、白字；宏利綠永遠係主色。
- 頁頭：跟 claimsreport，淺色底；鎖住喺頂；第一行 icon + 工具名 + 分頁掣（名右邊，手機落第二行）+ 按鈕，手機都要見到工具名；工具名下面一行細字簡介（15 字以內、唔用句號）。
- 「分享呢個方案」（有客人個人化設定先要，冇就刪走呢行）：用 `mkShare()`，連結包括設定、撳開重現方案，唔可以包括客人姓名。
- 版面：內容最闊 1320px，兩邊留白 `clamp(16px, 3vw, 32px)`；平板、手機唔可以橫向捲動。
- Icon：用 `mkpa-tools/_standard/make-icons.py` 產生（圖形 `【圖形名】`，宏利綠圓角方塊 + 白色線條），標題旁、瀏覽器分頁、加至主畫面都用同一個；唔好自己換第二個風格。標題旁 icon 大細跟頁頭標題（約 24–40px），唔使硬性統一 32px。
- 版權行：© 年份 Michael Koo Protection Alliance (MKPA). 版權所有。
- 介面用繁體中文（香港用語）；手機闊度 375px 唔可以橫向捲動。
